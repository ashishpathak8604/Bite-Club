# 🍔 Bite Club — Seriously Good Food

**A playful, modern restaurant website built to make food look as good as it tastes.**

🔗 **Live Website:** [https://biteclub-liv.vercel.app/](https://biteclub-liv.vercel.app/)

Bite Club is a vibrant restaurant website designed around a fun, expressive visual identity. It combines bold typography, warm colours, playful illustrations, interactive elements, and an engaging browsing experience to bring a restaurant brand to life online.

From exploring the menu to discovering the restaurant's story and browsing customer reviews, every page is designed to feel welcoming, intuitive, and visually memorable.

---

## ✨ Features

- 🏠 **Home Page** — An engaging landing experience introducing the Bite Club brand.
- 🍕 **Interactive Menu** — Browse food items and explore menu categories.
- 💛 **About Us** — Discover the restaurant's story, philosophy, ingredients, and team.
- ⭐ **Customer Reviews** — Explore customer feedback with rating filters and sorting options.
- 📸 **Photo Gallery** — Browse restaurant and food photography through category filters and an interactive lightbox.
- 📅 **Reservation Experience** — A dedicated interface for exploring table reservations.
- 🛒 **Order Experience** — Easy access to the ordering interface.
- 🎨 **Playful UI Design** — Handcrafted visual details, bold borders, layered shadows, doodles, and zigzag section transitions.
- 📱 **Responsive Layout** — Designed to adapt to desktop, tablet, and mobile screens.
- ✨ **Micro-interactions** — Subtle hover effects, transitions, and interactive visual elements.

## 🎨 Design Philosophy

The goal was to move away from generic restaurant website templates and create something with its own personality.

The visual direction focuses on:

- Warm, food-inspired colours.
- Bold typography and playful headings.
- Rounded cards with expressive borders and shadows.
- Zigzag transitions between sections.
- Illustrated details and decorative doodles.
- Interactive cards and subtle movement.
- Consistent visual language across all pages.

Every section is designed to feel like part of the same brand rather than a collection of unrelated web pages.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone <YOUR_REPOSITORY_URL>
```

### 2. Navigate into the project

```bash
cd bite-club
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

### 5. Build for production

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
